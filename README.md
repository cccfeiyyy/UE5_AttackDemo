# UE5游戏demo

> 基于 Unreal Engine 5 开发的 3D 第三人称剑与魔法动作战斗游戏
> 
> 

本项目为融合**剑术近战连击**与**多元素魔法反应**双体系战斗玩法，完整实现了从战斗机制设计、角色控制器开发、敌人 AI 逻辑到关卡场景搭建的全流程工程实践。

---

## ✨ 核心特性

1. **双体系战斗框架**

    - 剑术体系：三段轻重攻击连击、格挡、完美闪避，操作命中可积攒元素能量

    - 魔法体系：火、水、雷、风多属性魔法，消耗元素能量释放，各自具备独立伤害与控制效果

2. **元素反应战斗机制（核心创新）**

    - 魔法命中敌人后产生短暂元素附着，叠加不同属性触发专属反应效果

    - 包含蒸发、超载、感电、风化等多组反应，兼顾爆发伤害、范围控制与持续输出

3. **差异化敌人与多阶段 BOSS**

    - 火 / 冰 / 雷属性小怪各具攻击模式：近战冲锋、远程减速、范围 AOE

    - BOSS 具备血量阈值触发的多阶段机制，技能与行动模式随阶段升级

4. **递进式试炼关卡**

    - 3 个战斗关卡难度线性提升：新手教学场→元素混合试炼→BOSS 决战

    - 白盒先行验证战斗空间，最终场景搭载 Lumen 全局光照呈现次世代画质

5. **沉浸式打击反馈**

    - 动画蒙太奇 \+ 根运动实现精准攻击判定

    - Niagara 粒子特效、相机震动、画面抖动多维度强化战斗手感

## 🛠️ 技术栈

|类别|技术方案|
|---|---|
|游戏引擎|Unreal Engine 5\.7|
|开发方式|蓝图为主，组件化架构设计|
|技能系统|Gameplay Ability System \(GAS\) 框架|
|动画系统|动画蒙太奇 \(Anim Montage\) \+ 根运动|
|特效系统|Niagara 粒子系统|
|AI 系统|行为树 \(Behavior Tree\) \+ 黑板组件|
|渲染特性|Lumen 全局光照 / Nanite 虚拟几何体|
|关卡管理|Level Streaming 关卡流送|

## 🚀 快速开始\(暂未开放工程文件\)

### 环境要求

- **引擎版本**：Unreal Engine 5\.7\.x

- **操作系统**：Windows 10 / Windows 11

- **推荐配置**：16GB 内存 \+ RTX 3060 及以上显卡

- **磁盘空间**：预留 10GB 以上可用空间

### 运行步骤

1. 克隆或下载本仓库到本地

```bash
git clone https://github.com/你的用户名/BladeOfElement.git
```

2. 双击 `BladeOfElement.uproject`，使用 UE 5\.3 打开项目

3. 等待引擎完成着色器编译与资源加载

4. 在内容浏览器中打开 `Maps/MainLevel` 关卡

5. 点击编辑器上方「播放」按钮即可进入游戏

## ⚔️ 核心战斗机制

### 标准战斗循环

近战连击积攒元素能量 → 闪避 / 格挡规避伤害 → 释放元素魔法造成附着 → 叠加属性触发元素反应爆发 → 循环输出击杀敌人

### 元素反应对照表

|元素组合|反应名称|战斗效果|
|---|---|---|
|火 \+ 水|蒸发|本次伤害倍率提升至 1\.5 倍|
|火 \+ 雷|超载|范围爆炸，强打断敌人并附加持续灼烧|
|水 \+ 雷|感电|触发连锁额外雷电伤害|
|任意元素 \+ 风|风化|持续对应元素伤害，敌人短暂禁锢|

## 📂 项目结构

```Plain Text
BladeOfElement/
├── Content/
│   ├── Blueprints/      # 蓝图脚本（角色、敌人、战斗组件、UI）

│   ├── Maps/            # 关卡场景（新手场/试炼场/BOSS战）

└── BladeOfElement.uproject
```
