## 📖 项目简介

《元素之刃》是一款融合**剑术近战连击**与**元素魔法反应**的单人动作战斗游戏。玩家通过近战操作积累元素能量，释放多属性魔法并触发元素连锁反应，在递进式试炼关卡中击败不同属性的敌人与多阶段 BOSS。

项目主打「操作有手感、策略有深度、战斗有反馈」的中小型独立游戏体验，完整覆盖了从战斗机制设计、数值推演、敌人 AI 逻辑到关卡与性能验证的全流程设计。

**一句话差异化**：同类动作游戏的战斗多是「近战 + 法术」的并行加法，《元素之刃》的战斗是**剑术攒能、元素爆发、反应连锁**的深度乘法——每一次挥剑都在为元素风暴蓄力，每一次施法都在改写战场局势。

## ✨ 核心设计亮点

### 1. 双体系战斗框架

- **剑术体系**：轻攻击（四段连击）、重攻击（破防）、格挡、闪避，所有近战行为都能积累元素能量
- **魔法体系**：火 / 水 / 雷 / 风四种元素魔法（对应数字键 1–4），消耗元素能量释放，各自具备独立的伤害与控制效果
- **武器附魔**：施法后武器附带对应元素，附魔期间近战命中也能施加元素附着；附魔由 Gameplay Tag 维持，持续到施放下一种元素魔法，**切换武器或收剑（`Q`）时立即失效**。但元素反应仍只能由魔法引爆
- **强耦合设计**：近战是元素能量的**唯一来源**，法术是爆发与控制的**核心出口**，二者互为支撑、不可分割

### 2. 元素反应战斗机制（核心创新）

魔法命中敌人后施加短暂的**元素附着**，在 3 秒附着窗口内以另一属性魔法命中即可触发专属反应，把单纯的「放技能」升级为「属性搭配决策」。

| 元素组合 | 反应名称 | 战斗效果 | 战术定位 |
| --- | --- | --- | --- |
| 火 + 水 | **蒸发** | 打出一次高伤害反应，伤害倍率提升至 1.5 倍 | 单体高爆发，针对精英怪 / BOSS 破局 |
| 火 + 雷 | **超载** | 范围爆炸，造成持续伤害并打断敌人动作 | 打断施法、持续压制密集敌人 |
| 水 + 雷 | **感电** | 雷电连锁造成持续高伤害，但无打断效果 | 稳定持续群伤，处理小怪群 |
| 火 / 水 / 雷 + 风 | **风化** | 减速敌人并造成伤害，同时扩散原有元素 | 控制 + 持续伤害，解锁空中战斗 |

> 风元素可与火 / 水 / 雷任意组合触发风化，因此上表 **4 类反应共覆盖 6 组元素组合**。

**四元素单体命中效果**

| 元素 | 命中效果 |
| --- | --- |
| 火 | 产生持续伤害（DOT 灼烧） |
| 水 | 减缓敌人 |
| 雷 | 提升自身伤害 |
| 风 | 解锁空中战斗 |

### 3. 四层嵌套战斗循环

从秒级生存操作到分钟级 BOSS 博弈，逐层支撑、循环递进，最终围绕「近战攒能 → 施法触发反应」展开：

| 层级 | 循环链路 | 设计作用 |
| --- | --- | --- |
| 基础生存操作（秒级） | 接近敌人 → 轻重攻击 → 识别前摇 → 闪避 / 格挡 → 回到输出位 | 维持生存与持续命中 |
| 元素能量资源（十数秒级） | 近战命中攒能 → 达阈值 → 释放魔法 → 能量清空 → 回归近战 | 建立剑术与魔法的资源强关联 |
| 元素反应爆发（数十秒级） | 施法附着 → 近战攒能 → 二次施法 → 触发反应 → 附着重置 | 战斗的伤害与策略核心 |
| BOSS 阶段博弈（分钟级） | 常规循环 → 血量阈值转阶段 → 适应新机制 → 调整元素策略 | 用阶段变化制造新挑战 |

### 4. 差异化敌人与多阶段 BOSS

所有敌人共用同一套基础行为树模板，通过属性组件与攻击数据差异化，实现「一套框架、多种风格」：

| 敌人属性 | 定位 | 攻击模式 | 元素特性 |
| --- | --- | --- | --- |
| 火属性 | 近战冲锋型 | 近战挥砍、蓄力冲锋、近身火焰爆发 | 附带灼烧 Debuff；火抗 50%，水抗 -20% |
| 水属性 | 远程控制型 | 水弹射击、水锥地刺、低血量水幕护盾 | 减速叠加多层后大幅减速；水抗 50%，火抗 -20% |
| 雷属性 | 范围 AOE 型 | 追踪雷球、大范围落雷、连锁闪电 | 概率造成麻痹打断；雷抗 50%，水抗 -20% |

**BOSS 三阶段血量阈值机制**：

| 阶段 | 血量区间 | 行为特点 | 霸体强度 |
| --- | --- | --- | --- |
| 一 · 常态试探 | 100% ~ 70% | 基础普攻与单一元素技能，节奏平缓，帮助玩家上手 | 较低，重击可打断 |
| 二 · 元素觉醒 | 70% ~ 30% | 攻击频率提升，解锁双元素组合技与范围 AOE | 中等，仅反应与重击可硬直 |
| 三 · 狂暴终态 | 30% 以下 | 移速 / 频率 / 伤害大幅提升，技能连招与全屏预警大招 | 高，仅弱点部位可硬直 |

### 5. 递进式试炼关卡

1. **新手试炼场**：单属性近战敌人，引导熟悉移动、攻击、闪避与单元素释放
2. **元素试炼场**：多属性小怪混合刷新，强制玩家主动利用元素反应提升输出效率
3. **BOSS 战关卡**：多阶段元素 BOSS 且具备阶段属性切换，全面检验操作与元素搭配策略

场景实现遵循「白盒先行验证战斗空间 → 导入外部模型启用 Lumen 全局光照」的两段式标准，并采用 Level Streaming 关卡流送实现分段加载与淡入淡出过渡。

### 6. 沉浸式打击反馈

- **动作层**：动画蒙太奇分段管理 + 根运动同步位移，命中瞬间 2 帧卡肉强化重量感
- **判定层**：武器骨骼绑定盒体碰撞 + Anim Notify 开关判定帧，避免多段误判
- **视觉层**：Niagara 粒子特效、刀光、弹刀金属火花、屏幕闪光与径向缩放
- **相机层**：重击 / 弹刀触发相机震动，进入战斗自动拉近视角

## 🎯 操作说明

| 按键 | 功能 |
| --- | --- |
| `W` / `A` / `S` / `D` | 角色移动 |
| 鼠标移动 | 控制视角 |

| 鼠标中键 | 锁定 / 解锁敌人 |

## 🔢 关键数值设计一览

| 项目 | 数值 |
| --- | --- |
| 轻攻击前摇 / 判定 | 0.15s 前摇，命中判定持续 3 帧 |
| 重攻击前摇 | 0.4s，破防速度为轻攻击的 3 倍 |
| 连击窗口 / 输入缓冲 | 0.8s 窗口，动作播放至 70% 即可缓存下一段输入 |
| 闪避 | 全程 0.5s，前 0.2s 无敌帧 |
| 完美格挡判定窗口 | 攻击判定生效前 0.1s，免伤 100% 并触发 0.5s 弹刀硬直 |
| 完美闪避判定窗口 | 攻击判定生效前 0.15s，无敌帧延长且不消耗体力 |
| 普通格挡减伤 | 正面 70% |
| 元素能量获取 | 轻击 2 点 / 重击 10 点 / 完美闪避 8 点 / 弹刀 12 点 |
| 弱点命中 | 伤害 +50%，额外回能 +3 点 |
| 元素附着持续 | 3 秒（同元素刷新，不叠层） |
| 元素反应冷却 | 同目标同反应 0.5s |
| 元素抗性 | 同属性敌人受到对应元素伤害降低 50%，无绝对免疫 |

## 🛠️ 技术栈

| 类别 | 技术方案 |
| --- | --- |
| 游戏引擎 | Unreal Engine 5.7 |
| 开发方式 | 蓝图为主、组件化架构；底层战斗组件与 GAS 核心逻辑以插件实现 |
| 技能系统 | Gameplay Ability System (GAS) — 技能、属性、Buff / Debuff 统一管理 |
| 元素系统 | Gameplay Tag 标记元素附着状态 + Gameplay Effect 结算伤害与控制 |
| 动画系统 | 动画蒙太奇 (Anim Montage) + 根运动 (Root Motion) + Anim Notify |
| 特效系统 | Niagara 粒子系统 |
| AI 系统 | 行为树 (Behavior Tree) + 黑板 (Blackboard) + EQS 环境查询 |
| 渲染特性 | Lumen 动态全局光照 / Nanite 虚拟几何体 |
| 关卡管理 | Level Streaming 关卡流送 + 淡入淡出过渡 |
| 数据配置 | 数据表 (Data Table) 驱动元素反应规则，便于横向扩展 |
