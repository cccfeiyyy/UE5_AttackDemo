## 1. 游戏概述
### 1.1 核心定位
《元素之刃》是一款融合**剑术近战连击**与**元素魔法反应**的单人动作战斗游戏。玩家通过近战操作积累元素能量，释放多属性魔法并触发元素连锁反应，在递进式试炼关卡中击败不同属性的敌人与多阶段BOSS，主打「操作有手感、策略有深度、战斗有反馈」的中小型独立游戏体验。

### 1.2 设计目标
1. **操作门槛低**：基础移动、攻击、闪避逻辑直观易懂，新手可快速上手
2. **战斗策略深度**：通过元素反应机制鼓励玩家搭配技能组合，而非单一普攻输出
3. **强打击反馈**：通过动画、粒子特效、相机震动多层级强化战斗手感
4. **次世代画面表现**：依托UE5渲染特性实现高质量场景与特效呈现

### 1.3 参考原型
- 近战打击手感与剑法体系：《巫师3：狂猎》
- 元素交互数值体系与反应机制：《原神》

### 1.5 竞品参考

|  游戏  | 借鉴点 | 差异化 | 《元素之刃》差异化声明 |
|---------|--------|--------|----------------|
| 《巫师 3：狂猎》 | 剑术 + 法印的双体系战斗框架、近战打击手感与动作逻辑 | 强化元素魔法的交互深度，将单一工具性法印升级为可连锁触发的元素反应系统，与近战能量获取强绑定 |不只是 “近战为主、法术为辅” 的工具式设计，而是剑术与元素魔法深度耦合的双循环体系—— 近战是能量的唯一来源，法术是爆发与控制的核心，二者互为支撑、不可分割 |
| 《原神》 | 元素反应的数值设计逻辑、多属性交互的策略深度 | 采用第三人称即时动作近战玩法，强调操作手感与近身博弈，元素释放与近战节奏强绑定，而非脱离普攻的独立技能循环 | 元素反应不是脱离操作的数值倍率工具，而是与近战操作深度绑定的战斗节奏核心—— 你必须靠贴身剑术拼刀积攒能量，才能触发元素反应的爆发效果 |
| 《鬼泣 5》 | 连击系统的衔接逻辑、动作打击反馈、招式输入缓冲设计 | 在纯动作连招的基础上加入元素能量与反应系统，战斗策略维度从连招延伸至属性搭配与资源管理 | 连击不只是为了观赏性与评分，更是元素能量的积累过程，每一段命中都在为下一次元素反应爆发蓄力，操作与策略形成完整闭环 |
| 《艾尔登法环》 | BOSS 多阶段设计、闪避 /格挡的博弈机制、战斗节奏把控  |加入元素附着与属性克制逻辑，BOSS 战同时考验操作熟练度与元素策略选择，而非纯背板式的肌肉记忆挑战 | 战胜强敌不依赖单纯的操作熟练度，更需要针对敌人属性选择元素组合，用超载打断、超导控制、蒸发爆发实现策略反制 |

> **一句话差异化**：同类动作游戏的战斗多是 “近战 + 法术” 的并行加法。《元素之刃》的战斗是**剑术攒能、元素爆发、反应连锁**，的深度乘法 —— 每一次挥剑都在为元素风暴蓄力，每一次施法都在改写战场的局势。

## 2. 核心战斗体系
### 2.1 双体系战斗框架
#### 2.1.1 剑术体系
- **基础操作**：轻攻击、重攻击、四段连击、空中攻击、格挡、闪避，全部操作积累法力值
- **操作特性**：
  - 轻攻击：出手快、硬直小，是连击与攒能的核心手段
  - 重攻击：破防效果强，命中后可大幅积攒元素能量
  - 格挡/完美闪避：规避伤害，成功触发时恢复体力并额外获得元素能量
- **资源关联**：近战命中敌人是法力值的主要获取途径

#### 2.1.2 魔法体系
- 包含**火、冰、雷、水、风**五种基础元素魔法
- 释放消耗对应元素能量，各元素具备独立基础伤害与控制效果
- 魔法命中敌人后会在目标身上留下短暂元素附着，为元素反应提供触发条件

### 2.2 标准战斗循环
靠近敌人 → 轻重攻击连击积攒元素能量 → 闪避/格挡规避伤害 → 切换元素魔法释放并触发元素反应 → 击杀敌人获取战斗奖励

---

## 3. 元素反应系统（核心创新设计）
### 3.1 触发规则
魔法命中敌人后会产生短时间的元素附着状态；在附着持续时间内，若目标受到另一属性魔法攻击，将触发对应元素反应，产生额外伤害、控制或范围效果。

### 3.2 元素反应对照表
| 元素组合 | 反应名称 | 战斗效果 |
|----------|----------|----------|
| 火 + 水 | 蒸发 | 本次伤害倍率提升至1.5倍 |
| 火 + 雷 | 超载 | 触发范围爆炸，强打断敌人动作并附加持续灼烧伤害 |
| 水 + 雷 | 感电 | 触发连锁雷电，对范围内敌人造成额外雷电伤害 |
| 任意元素 + 风 | 风化 | 造成持续对应元素伤害，并使敌人短暂减速甚至禁锢 |

## 4. 敌人设计
### 4.1 基础AI框架
所有敌人共用行为树基础逻辑，状态流转为：
**巡逻 → 感知玩家 → 追击 → 近战/魔法攻击 → 受击硬直 → 死亡**

### 4.2 差异化属性敌人
| 敌人属性 | 攻击模式 | 战斗特点 |
|----------|----------|----------|
| 火属性 | 近战冲锋型 | 高移速、高近战伤害，擅长贴脸压制 |
| 冰属性 | 远程控制型 | 远程发射冰弹，附带减速效果，保持距离作战 |
| 雷属性 | 范围AOE型 | 蓄力释放大范围雷电攻击，伤害高但前摇长 |

### 4.3 BOSS多阶段机制
- 最终BOSS采用血量阈值分段机制
- 血量降至预设节点时，自动切换战斗阶段，解锁全新攻击技能与行动模式
- 阶段越高，攻击频率、伤害与范围越强，对玩家元素搭配策略要求越高

## 5. 关卡设计
### 5.1 整体规划
设计3个递进式战斗试炼关卡，难度线性提升，完成从教学到综合考验的过渡。

### 5.2 关卡详情
1. **新手试炼场**
   - 定位：基础操作教学
   - 内容：仅投放单一近战敌人，引导玩家熟悉移动、攻击、闪避、单元素魔法释放
2. **元素试炼场**
   - 定位：元素反应玩法教学
   - 内容：多属性小怪混合刷新，强制引导玩家主动利用元素反应提升输出效率
3. **BOSS战关卡**
   - 定位：综合能力考验
   - 内容：多阶段元素BOSS，全面检验玩家操作、闪避时机与元素搭配策略

### 5.3 场景实现标准
- 白盒先行：使用UE原生Geometry Bsp搭建关卡白盒，验证战斗空间、距离、掩体合理性
- 最终品质：导入外部场景模型资源，启用Lumen全局光照与后期处理盒优化光影表现
- 加载方案：采用Level Streaming关卡流送实现场景分段加载，搭配淡入淡出过渡动画切换战斗区域

## 6. 玩家操作与反馈
### 6.1 按键映射
| 按键 | 功能 |
|------|------|
| W / A / S / D | 角色移动 |
| 鼠标移动 | 控制视角 |
| 鼠标左键 | 轻攻击（支持三段连击） |
| 鼠标右键 | 格挡 |
| Alt | 闪避 |
| Q | 拔剑 / 收剑 |
| 数字键 1-4 | 释放对应元素魔法 |
| 鼠标中键 | 锁定 / 解锁敌人 |

### 6.2 战斗手感反馈
- **连击系统**：输入缓冲 + 动画蒙太奇插槽判定，实现三段轻攻击无缝衔接；攻击判定采用盒体碰撞检测
- **相机反馈**：进入战斗自动拉近视角；角色受击、重击命中时触发相机震动与画面短时抖动
- **特效反馈**：依托Niagara粒子系统制作元素技能、元素反应爆炸、受击飞溅等视觉效果

## 7. 技术实现方案
### 7.1 核心引擎特性
- Nanite虚拟几何体：高精度模型无LOD渲染，保障场景画质
- Lumen动态全局光照：实时光影反弹，提升场景沉浸感
- Niagara VFX系统：复杂粒子特效编辑与实时渲染
- Gameplay Ability System（GAS）：官方标准化技能框架，统一管理技能、属性、Buff/Debuff，是元素反应机制的底层载体

### 7.2 开发模式
采用**蓝图为主、组件化**的开发模式：
- 底层战斗组件、GAS核心逻辑使用插件编写，保障运行效率
- UI交互、关卡逻辑、特效控制、简易流程控制使用蓝图快速迭代开发

### 7.3 关键技术模块
1. **动画系统**：动画蒙太奇分段管理攻击、施法、受击动作片段，配合根运动同步动作位移与攻击判定
2. **AI系统**：行为树 + 黑板组件驱动敌人逻辑，实现多状态自动切换
3. **元素系统**：基于Gameplay Tag实现元素附着标记与反应触发判定

## 8. 测试与效果验证
### 8.1 功能测试
- 覆盖模块：基础移动与视角、轻重攻击连击、闪避格挡、元素魔法释放、全部元素反应触发逻辑、敌人AI行为、关卡切换、伤害数值UI
- 测试结果：所有核心功能用例均通过，无逻辑Bug

### 8.2 性能测试
- 测试环境：拯救者Y7000P，RTX4060显卡、16GB内存，Windows 11系统
- 测试结果：高画质预设下平均稳定60FPS以上
- 优化项：验证了Nanite/Lumen开关对帧率的影响，针对大量粒子同时生成的场景做了帧率波动优化

### 8.3 用户体验反馈
小规模玩家试玩调研显示：
- 剑与魔法+元素反应的组合玩法可玩性良好
- 操作流畅度达标
- 元素搭配具备丰富的策略空间
- 打击反馈与视觉表现符合预期

## 9. 后续迭代规划
### 9.1 当前版本不足
1. 关卡以纯战斗场景为主，缺少剧情叙事与野外探索内容
2. 武器与魔法种类较少，完整RPG角色成长、装备养成体系尚未实现
3. 敌人AI种类有限，BOSS阶段机制可进一步丰富
4. 无专业动作捕捉资源，部分动作动画流畅度存在提升空间

### 9.2 未来拓展方向
- **养成系统**：新增装备、词条、等级成长系统，拓展RPG养成深度
- **内容扩充**：增加更多元素种类与反应组合，新增可操控角色
- **叙事与地图**：开放线性探索地图，补充主线剧情与支线任务
- **品质升级**：引入动作捕捉资源，优化动画过渡与打击特效，进一步提升战斗沉浸感
